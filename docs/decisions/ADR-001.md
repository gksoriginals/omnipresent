# ADR-001: Runtime and language

Recorded: 17 October 2026 (retrospective). Status: **Provisional**.

## Context and alternatives

A shared typed web protocol and process isolation match the current implementation. Rust/Go and other runtimes were considered but not benchmarked.

## Decision

TypeScript/React/Node coordinator with isolated Python speech workers.

## Evidence

EXP-001, EXP-020. See the [register](../validation/test-register.md) and [experiment reports](../validation/experiment-reports.md) for methods, failures and limitations. Versioned package/runtime locks and the software audit identify the current implementation.

## Consequences and revisit conditions

Keep queues bounded and measure end-to-end latency under combined load. Revisit on measured scheduling, memory or concurrency limits.
