# ADR-007: Material ingestion and visual tools

Recorded: 17 October 2026 (retrospective). Status: **Provisional**.

## Context and alternatives

Synthetic extraction/tool fixtures and actual model tool use exist. Alternatives were not ranked.

## Decision

MarkItDown/Pillow ingestion with bounded Mermaid and Recharts generation tools.

## Evidence

EXP-005, EXP-007. See the [register](../validation/test-register.md) and [experiment reports](../validation/experiment-reports.md) for methods, failures and limitations. Versioned package/runtime locks and the software audit identify the current implementation.

## Consequences and revisit conditions

Source checks do not prove correct interpretation. Revisit on representative uploads, parser failure handling and independent factual review.
