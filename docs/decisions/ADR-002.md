# ADR-002: Preparation agent orchestration

Recorded: 17 October 2026 (retrospective). Status: **Provisional**.

## Context and alternatives

Actual local calls and failure recovery exist. LangGraph, Deep Agents and other orchestration options were researched only; LiveKit remains deferred pending media/transport requirements.

## Decision

AI SDK 7 with separate interview/story/realtime roles and Zod tool contracts.

## Evidence

EXP-002–005. See the [register](../validation/test-register.md) and [experiment reports](../validation/experiment-reports.md) for methods, failures and limitations. Versioned package/runtime locks and the software audit identify the current implementation.

## Consequences and revisit conditions

No framework superiority claim. Revisit if durable workflow, handoff or media requirements exceed current coordination.
