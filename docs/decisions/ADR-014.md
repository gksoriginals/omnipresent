# ADR-014: Cloudflare Clef as a bounded decision candidate

Recorded: 17 October 2026. Status: **Promising offline candidate; no live-default migration**.

## Context and alternatives

The user requested Cloudflare's System One models. Clef, Clef-flash and Clef-omni are available through the existing OpenRouter Decisions transport. EXP-027 verifies connectivity; EXP-028/029 compare both semantic-gated and raw menus against a fresh Jev reference on unchanged inputs. No new framework, account, credential or service deployment is required.

## Decision

Use **EmbeddingGemma 2 raw shortlist plus bounded Clef-omni choice** as the next experimental integration candidate, retaining the FSM from ADR-012 for temporal control. Keep Jev as a reference and Clef-flash as a cost alternative. This updates ADR-013's earlier Jev candidate preference; it is not a production model selection or application-default change.

## Evidence

[Full report and protocol](../research/cloudflare_clef_results.md): all three Clef variants match 24/24 full action/topic labels on raw menus; fresh Jev matches 21/24. Omni has the lowest observed raw median (383 ms), but Jev's p95 is lower (519 versus 584 ms) and recorded cost is lower. Flash has the lowest recorded raw-arm cost. Gated Cloudflare scores fall to 20–21/24 because candidate removal and hold/context confusion remain. All 192 quality requests exactly match retained reference payloads except model selection.

## Consequences and revisit conditions

This is a reused synthetic set, one nonrandomized sweep, without independent labels. Preserve the OpenRouter server-only credential boundary, host-validated prepared references and explicit hold/context choices. Do not infer media support, local self-hosting performance, calibrated confidence or live-loop reliability from text-only hosted results. Obtain independent/perturbed examples and repeated timings; then validate the asynchronous FSM/selector/feedback combination before an opt-in voice trial. Revisit the candidate preference on those results, especially tail latency and missing-evidence behavior.
