# ADR-015: Hybrid component search with experimental family priors

Recorded: 17 October 2026. Status: **Offline experiment; no default migration**.

## Context

The user proposed System One family probabilities before exact content retrieval, required hybrid search, and chose hosted OpenRouter Clef when local weights would add storage. Local Clef setup was stopped before weights were downloaded and temporary directories were removed. Existing text embedding infrastructure remains in use.

## Decision

Use BM25 plus normalized dense similarity with reciprocal rank fusion for the new component experiment. Retain current-context family routing and prior-context speculative prefetch as alternative candidate-generation paths, not replacements for grounded publication decisions. Keep Clef hosted through the existing OpenRouter transport. Forecasts alone cannot change the audience canvas.

## Evidence

[EXP-031 report and protocol](../research/prediction_first_results.md): current top-two family routing scores about 40% fewer components while retaining 12/12 positive candidates. Complete actions are 13/18 versus retrieval-first 14/18. Prior-context top-two forecasts include the correct next family in 7/12 positives and prefetch exact references in 4/12. Query encoding is about 27 ms versus sub-millisecond ranking and hundreds of milliseconds for hosted calls; reversing serial order alone is not a speedup proof.

## Consequences and revisit conditions

Treat scores as uncalibrated priors. Validate forecast scope, story position, epoch, age and corpus revision. Same story position does not mean unchanged meaning: five approximate lease reuses save calls but lose both positive next-family cases that reuse a lease in this replay. Test topic/family availability metadata, content-aware refresh, a global hybrid escape path and larger natural traces before using hard masks in a live controller. Preserve current evidence checks, prepared references and FSM timing controls; measure virtual prefetch readiness separately from authorized visible response latency.
