# ADR-011: Desktop packaging

Recorded: 17 October 2026 (retrospective). Status: **Deferred**.

## Context and alternatives

This is a sequencing decision; no packaged desktop experiment or shell benchmark exists.

## Decision

Validate the adaptive web core before Electron or another desktop shell.

## Evidence

PLAN-003. See the [register](../validation/test-register.md) and [experiment reports](../validation/experiment-reports.md) for methods, failures and limitations. Versioned package/runtime locks and the software audit identify the current implementation.

## Consequences and revisit conditions

Revisit for operating-system integration, capture, offline distribution and packaging requirements after core decision behaviour is validated.
