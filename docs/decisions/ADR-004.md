# ADR-004: Generative presentation rendering

Recorded: 17 October 2026 (retrospective). Status: **Parallel evaluation**.

## Context and alternatives

Both adapters render actual compositions. Native generated-format probes failed for both; neither library is selected as winner.

## Decision

A bounded presentation catalog with common components and OpenUI/json-render adapters.

## Evidence

EXP-011–014. See the [register](../validation/test-register.md) and [experiment reports](../validation/experiment-reports.md) for methods, failures and limitations. Versioned package/runtime locks and the software audit identify the current implementation.

## Consequences and revisit conditions

Keep renderer-neutral validation. Revisit using native streaming, patches, error recovery, bundle cost and composition-quality evidence.
