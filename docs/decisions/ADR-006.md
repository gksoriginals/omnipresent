# ADR-006: Retrieval and caching

Recorded: 17 October 2026 (retrospective). Status: **Text retrieval prototype measured; production selection pending**.

## Context and alternatives

Exact-cache replay is measured. Text-only EmbeddingGemma 2 retrieval and exact scoped query caching are measured in EXP-024/025; see [ADR-013](ADR-013.md). Media retrieval and similarity-based answer reuse remain unvalidated.

## Decision

Retain bounded exact reuse; investigate prepared-asset semantic retrieval with EmbeddingGemma.

## Evidence

EXP-006, EXP-024–026, PLAN-002. See the [register](../validation/test-register.md) and [experiment reports](../validation/experiment-reports.md) for methods, failures and limitations. Versioned package/runtime locks and the software audit identify the current implementation.

## Consequences and revisit conditions

Need corpus/query labels, candidate recall, grounding, latency, invalidation and memory tests before adoption. Semantic reuse must respect project/revision/source boundaries.
