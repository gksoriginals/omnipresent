# ADR-010: Workspace persistence

Recorded: 17 October 2026 (retrospective). Status: **Provisional local prototype**.

## Context and alternatives

Software tests and browser observations cover isolation, reload and undo. No database comparison was run.

## Decision

Versioned browser-local projects, stable story upsert and reversible removal.

## Evidence

EXP-008–010, EXP-020. See the [register](../validation/test-register.md) and [experiment reports](../validation/experiment-reports.md) for methods, failures and limitations. Versioned package/runtime locks and the software audit identify the current implementation.

## Consequences and revisit conditions

No account, cross-device or multi-tab conflict guarantee. Revisit with explicit collaboration/durability requirements; avoid unrequested database migration.
