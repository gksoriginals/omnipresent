# ADR-013: Semantic prepared-content shortlist and bounded selection

> Candidate preference update: [ADR-014](ADR-014.md) records the subsequent Cloudflare comparison. The evidence below remains the earlier Jev/Laya stage.

Recorded: 17 October 2026. Status: **Measured offline prototype; opt-in integration candidate**.

## Context and alternatives

The lexical controller prototype missed paraphrases and included unavailable evidence. EXP-024/025 compare BM25, text-only EmbeddingGemma 2, RRF, and bounded Laya/Jev selection. A small in-memory index avoids introducing a vector database or new agent framework.

## Decision

Keep pinned EmbeddingGemma 2 text retrieval plus bounded Jev choice as the next integration candidate, with the FSM from ADR-012 for temporal guards. Preserve explicit hold/request-context. Do not deploy a universal cosine cutoff or select Laya on latency alone. No default presentation path has changed.

## Evidence and limitations

[Report and exact run artifacts](../research/semantic_retrieval_results.md): raw semantic top-two recall 21/21 required references versus BM25 19/21; gated semantic plus Jev 22/24 full actions versus BM25 plus Jev 20/24. The gate rejects two valid queries. Ungated Jev remains 22/24 but shows an irrelevant related topic for a missing-cost request and misses one preparation handoff. Local Laya matches only 7–11/24. The dataset is small, synthetic and developer-labelled; the follow-up reused evaluation cases. No independent holdout or production winner is established.

## Consequences and revisit conditions

Embeddings rank prepared text only and never generate facts. Index/cache identity includes project, preparation/corpus and embedding-space revisions. Model choices resolve only to registered host-validated compositions; probabilities are not calibrated temporal confidence. The additional Python runner is experimental, loopback-only and explicitly started with retrieval:serve. Media encoders and semantic answer caching are not validated.

Add explicit missing-evidence handling and independent labels, then exercise the asynchronous FSM/selector/feedback integration before an opt-in audio/browser trial. Revisit the embedding/model/menu/threshold choices on those results and measured contention, memory and asset-mode behavior.
