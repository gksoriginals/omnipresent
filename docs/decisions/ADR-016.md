# ADR-016: Adopt the evidence-first modular presentation baseline

17 October 2026 · Accepted for local development by explicit user request.

## Decision

Make the evidence-first pipeline the default live presentation runtime. Use local EmbeddingGemma 2 hybrid search, exact prepared cue bindings, bounded intent/evidence checks, hosted Clef-omni for unresolved selections and final host validation. Keep useful tested decision classes behind a common interface; defaults are configuration rather than provider branches inside business logic. Preserve separate language, embedding and streaming-speech interfaces.

The user explicitly authorized dropping incompatible saved stories and removing unhelpful code instead of maintaining migrations. Old story/slide direction and general-LLM canvas generation are removed from the live coordinator. Unsupported or unselected model paths remain documented as research, not executable defaults. Useful alternative decision adapters remain available behind the same evidence boundary.

## Rationale and evidence

[EXP-037](../research/evidence_gate_results.md) passed authored development quality and repeated decision-path latency gates. It supports adopting this as an engineering baseline, not independent production acceptance. The user requested implementation after those limits were explained. [Baseline diagrams and defaults](../architecture/baseline.md) describe the implementation and remaining scope.

New story generation creates declared evidence contracts, and save records presenter approval. Independent review stays pending; actual/source-backed, illustrative and audited status remain distinct. Local development uses presenter-reviewed contracts unless strict independent review is configured. This is an explicit development policy, not a claim that review requirements have been satisfied.

## Alternatives and consequences

Continuing the general LLM presentation director would preserve broader but insufficiently constrained behavior and the coupling the user asked to remove. Migrating old stories would invent evidence bindings for material that was not authored against this baseline. Neither is retained.

The bounded interpreter can over-abstain on spontaneous speech. Single-component selection and retention are the current policy scope; multi-component synthesis is not established by renderer support. Independent source review, natural speech, real media and visible-paint latency remain future acceptance work. Revisit parser/context resolution when representative speech shows poor useful-selection coverage; never solve it by removing final evidence validation.
