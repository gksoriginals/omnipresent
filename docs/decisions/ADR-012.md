# ADR-012: Offline deterministic presentation control

Recorded: 17 October 2026. Status: **Experimental baseline; not integrated into the live app**.

## Context and alternatives

The live decision model needs a bounded candidate shortlist and temporal control. EXP-022 compares priority rules, an FSM, stateful behaviour tree and hybrid on the same prepared candidates and timestamped events. Seven named tests add invariants and retrieval boundary coverage. No new framework is needed for this small prototype.

## Decision

Use the small FSM with explicit priority guards as the next experimental baseline. Keep BT and hybrid implementations for future comparison. All temporal variants match the same 48-action regression contract; tiny timing differences do not select a winner. The simpler current stability contract supports this provisional engineering choice.

Keep candidate retrieval and semantic model selection independently measurable. Do not migrate the audience canvas to the lexical prototype: exact candidate-set accuracy is only 4/9 cases. The existing app default remains unchanged.

## Evidence and limitations

[EXP-022 report](../research/controller_comparison.md), its immutable raw runs, and EXP-023 software audit. Fixtures were developer-authored alongside implementation, not an untouched holdout. Rules lack temporal confirmation by design; this is not proof of a fundamental notation advantage. No new model/audio/browser trials ran.

## Consequences and revisit conditions

No general LLM call is required by these policy prototypes. This does not yet establish complete speech understanding without a model. Semantic retrieval and bounded System One choice have now been exercised in [ADR-013](ADR-013.md). Improve missing-content handling, obtain independent labels, then validate async cancellation and live behavior. Revisit BT/hybrid if priority branches, multi-step actions or policy maintenance become measurably harder in the FSM.
