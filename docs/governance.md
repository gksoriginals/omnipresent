# Governance

Omnipresent is maintained by [gksoriginals](https://github.com/gksoriginals). Maintainers decide architecture, releases and contributions through public issues and PRs. Research claims must link to scoped evidence; negative findings remain visible.

External contributors should propose substantial product or architecture changes in an issue before implementing them. Accepted contributions do not automatically grant maintainer access. Maintainers may invite contributors based on sustained technical work, review and community participation.

Main is an experimental development branch. No stable release or compatibility policy exists yet. Maintainers will document a release process before publishing supported packages or desktop binaries. See the roadmap and contribution/security policies.
